### Multiple Choice Questions

1. Which of the following is used to create an object in Java?
   - A. `class`
   - B. `new`
   - C. `object`
   - D. `create`

   **Answer:** B. `new`

2. Which concept hides implementation details?
   - A. Inheritance
   - B. Polymorphism
   - C. Abstraction
   - D. Compilation

   **Answer:** C. Abstraction

3. Which concept is mainly associated with protecting data?
   - A. Encapsulation
   - B. Inheritance
   - C. Compilation
   - D. Overloading

   **Answer:** A. Encapsulation

4. Which keyword is used for inheritance between classes?
   - A. `implements`
   - B. `extends`
   - C. `inherits`
   - D. `superclass`

   **Answer:** B. `extends`

5. Which is an example of compile-time polymorphism?
   - A. Method overriding
   - B. Method overloading
   - C. Inheritance
   - D. Encapsulation

   **Answer:** B. Method overloading

6. Which is the correct Java identifier?
   - A. `1student`
   - B. `student name`
   - C. `studentName`
   - D. `class`

   **Answer:** C. `studentName`

7. Which data type is used to store a single character?
   - A. `String`
   - B. `char`
   - C. `character`
   - D. `text`

   **Answer:** B. `char`

8. Which operator represents logical AND?
   - A. `&`
   - B. `||`
   - C. `&&`
   - D. `!`

   **Answer:** C. `&&`

9. Array indexing in Java starts from:
   - A. 1
   - B. -1
   - C. 0
   - D. 2

   **Answer:** C. 0

10. Which method is used to sort an array using the Arrays class?
    - A. `Arrays.order()`
    - B. `Arrays.sort()`
    - C. `Arrays.arrange()`
    - D. `Arrays.organize()`

    **Answer:** B. `Arrays.sort()`

11. Which field gives the number of elements in an array?
    - A. `size`
    - B. `length()`
    - C. `length`
    - D. `count`

    **Answer:** C. `length`

12. Which statement is used to make a decision based on multiple fixed values?
    - A. `switch`
    - B. `array`
    - C. `continue`
    - D. `import`

    **Answer:** A. `switch`

13. Which component of Java executes bytecode?
    - A. JDK
    - B. JVM
    - C. JAR
    - D. Javadoc

    **Answer:** B. JVM

14. Which method was historically associated with cleanup before garbage collection?
    - A. `delete()`
    - B. `remove()`
    - C. `finalize()`
    - D. `destroy()`

    **Answer:** C. `finalize()`

15. Which of the following is true about `System.gc()`?
    - A. It always immediately performs garbage collection.
    - B. It deletes all objects.
    - C. It requests the JVM to perform garbage collection.
    - D. It closes the JVM.

    **Answer:** C. It requests the JVM to perform garbage collection.
